✏️ Input / Edit Data Nama Siswa

Masukkan satu siswa per baris dengan format NAMA,L atau NAMA,P. Bisa tempel daftar dari Excel (nama dan jenis kelamin dipisahkan TAB). Simpan data sebelum mulai mengacak.

Riwayat Semua Putaran

Progres otomatis tersimpan di browser. Gunakan Simpan Progres untuk mengunduh cadangan JSON dan Muat Progres untuk melanjutkan di perangkat lain.

Rekap Pemerataan Peran

P = pemain, W = wasit, S = pencatat skor. Siswa dengan kesempatan paling sedikit diprioritaskan.
